# 📋 Sistema de Gestão de Projetos

Sistema desenvolvido em Java utilizando a arquitetura MVC (Model-View-Controller) para gerenciamento de projetos, usuários, equipes e tarefas.

## 🎯 Objetivo

O objetivo deste projeto é aplicar conceitos de Programação Orientada a Objetos (POO), organização em camadas e arquitetura MVC.

## 🚀 Funcionalidades

- Cadastro de Usuários
- Cadastro de Projetos
- Cadastro de Equipes
- Cadastro de Tarefas
- Interface gráfica em Java Swing
- Organização em arquitetura MVC
